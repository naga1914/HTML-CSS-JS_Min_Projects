# HTML, CSS, and JavaScript Mini Projects

Welcome to my collection of mini web projects! 🎉 This repository is a fun and educational way to practice and improve my web development skills. These small projects are designed to help me sharpen my HTML, CSS, and JavaScript abilities, and I'm super happy to have completed them! 🎉

---

## 🚀 Projects

Here’s a list of the mini-projects included in this repository:

### 1. **Animated Login UI**
A stylish animated login interface that gives users a smooth and dynamic entry experience.

- Features:
  - Smooth transitions for input fields.
  - Attractive animations and design.
  - Responsive layout for all devices.

### 2. **Click to Copy**
A simple app that allows users to easily copy text to their clipboard with just a click.

- Features:
  - Easy-to-use interface.
  - Copy-to-clipboard functionality.
  - Great for anyone who needs quick text copying.

### 3. **Click to Tweet**
Generate a tweetable message with just one click! This project helps you tweet a pre-defined message directly from the app.

- Features:
  - Click-to-tweet functionality.
  - Customizable text for different messages.
  
### 4. **Counter App**
A simple yet functional counter that increases and decreases numbers with the click of a button.

- Features:
  - Count up or down.
  - Display dynamic changes.
  
### 5. **Dark Mode Toggle**
Toggle between light and dark themes with a simple button, enhancing user experience based on their preferences.

- Features:
  - Easy-to-use dark mode toggle.
  - Saves theme preference in local storage.
  
### 6. **Input Character Count**
Displays the number of characters typed in a text input field, ideal for forms and user input validation.

- Features:
  - Real-time character count.
  - Provides feedback as users type.

### 7. **Model Popup**
A pop-up modal that appears on screen when triggered, perfect for displaying messages, forms, or images.

- Features:
  - Close and open buttons.
  - Styled modal with smooth transitions.

### 8. **Palindrome Checker**
Check if a string is a palindrome by reversing it and comparing it with the original input.

- Features:
  - Real-time palindrome checking.
  - Visual feedback on whether the input is a palindrome.

### 9. **Password Visibility Toggle**
Toggle visibility of a password input field with a simple eye icon.

- Features:
  - Show or hide password text.
  - Easy-to-use for secure password entry.

### 10. **Random Hex Color Generator**
Generate a random hex color code every time you click a button.

- Features:
  - Generates and displays a new color.
  - Displayed hex code for easy copying.

### 11. **Random Number Generator**
Generate a random number within a user-defined range.

- Features:
  - Generate numbers on click.
  - Dynamic input fields for range selection.

### 12. **Random Password Generator**
Generate strong, random passwords at the click of a button.

- Features:
  - Create secure passwords.
  - Customizable password length.

### 13. **Tip Calculator**
Calculate a tip amount based on the total bill and desired percentage.

- Features:
  - Real-time tip calculation.
  - Allows users to select tip percentage.

### 14. **Vertical Tabs**
Create vertical tabs that allow users to toggle between different content sections.

- Features:
  - Smooth tab transitions.
  - Easy-to-read vertical navigation.

### 15. **Vowel Counter**
Count the number of vowels in a given string of text.

- Features:
  - Displays the number of vowels.
  - Handles different cases (uppercase/lowercase).

### 16. **Weight Converter**
Convert between different units of weight (kg, lb, oz, etc.).

- Features:
  - Easy-to-use weight conversion tool.
  - Multiple units supported.

## 🔧 Setup Instructions

To set up any of the projects locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/naga1914/HTML-CSS-JS_Min_Projects.git
   cd HTML-CSS-JS_Min_Projects
   ```

2. **Open the project in your browser**:
   - Navigate to the project folder and open the `index.html` file in any browser.
   ```bash
   open index.html
   ```
